AR Checkers Online

เกมหมากฮอสไทยออนไลน์แบบ 2 ผู้เล่นผ่าน WebAR บนเบราว์เซอร์มือถือ

⚡ Stack: Node.js • Socket.io • A-Frame • MindAR
📱 Device: รองรับทั้ง iOS (Safari) และ Android (Chrome)
กดลูกศร → หรือกดปุ่ม ถัดไป ที่แถบด้านล่างเพื่อเริ่มการนำเสนอ
บทพูดหน้า 1: สวัสดีครับอาจารย์และเพื่อนๆ ทุกคน วันนี้กลุ่มผมขอเสนอโครงงาน "AR Checkers Online" ซึ่งเป็นการนำเกมกระดานดั้งเดิมอย่างหมากฮอสไทย มาผสานเข้ากับเทคโนโลยี WebAR ทำให้เพื่อนๆ ในห้องเรียนสามารถหยิบสมาร์ตโฟนขึ้นมาสแกน QR Code แล้วฉายกระดานหมากฮอส 3 มิติลงบนโต๊ะเรียนเพื่อเล่นด้วยกันแบบเรียลไทม์ได้ทันที โดยไม่ต้องติดตั้งแอปพลิเคชันใดๆ ครับ
💡 ที่มาและความสำคัญ

ทำไมต้องเป็น WebAR Checkers?

แก้ปัญหาและข้อจำกัดของเกมกระดานแบบเดิมและแอปทั่วไป

📦
ไม่ต้องพกพากระดานจริง
กระดานหมากฮอสและตัวหมากจริงมีโอกาสตกหล่นสูญหาย แต่ด้วย AR ผู้เล่นเพียงส่องภาพมาร์กเกอร์แผ่นเล็กๆ ก็จำลองกระดานขึ้นมาได้ทันที
🚀
Zero Installation (WebAR)
แอป AR ส่วนใหญ่ต้องดาวน์โหลดจาก App Store / Play Store ขนาดหลายร้อย MB แต่โปรเจกต์นี้ทำงานบนเบราว์เซอร์ 100% สแกน QR แล้วเล่นได้ใน 3 วินาที
🛡️
Server-Authoritative
เล่นหมากฮอสในห้องเรียนมักมีปัญหา "ลืมกิน", "กินผิดกฎ" หรือ "แอบโกง" ระบบนี้มีเซิร์ฟเวอร์คอยคุมกฎบังคับกินและการสลับตาแบบ 100%
บทพูดหน้า 2: จุดเริ่มต้นของโครงงานนี้เกิดจากความต้องการนำเทคโนโลยี AR มาใช้จริงในห้องเรียนครับ ปัญหาของ AR ในอดีตคือผู้ใช้ต้องดาวน์โหลดแอปขนาดใหญ่ ทำให้เพื่อนๆ ไม่อยากติดตั้ง แต่ด้วยเทคโนโลยี WebAR ที่รันบน WebGL และ WebRTC ผ่านเบราว์เซอร์ ทำให้ทุกคนสามารถเข้าร่วมกิจกรรมในห้องเรียนได้ทันที
🏗️ สถาปัตยกรรมระบบ

Server-Authoritative Architecture

การออกแบบระบบที่ปลอดภัย ไม่เชื่อถือการคำนวณจากฝั่งผู้เล่น (Client)

🖥️
Backend Server
- Express: ให้บริการ Static Web Assets
- Socket.io: จัดการ Matchmaking Queue และห้องเกม (Room)
- Rules Engine: ตรวจสอบตาเดินทุกครั้ง ห้ามข้ามขั้นตอน
📱
Frontend Client
- ส่งเพียงคำสั่งย้ายหมาก { from: [r,c], to: [r,c] }
- รับ Board State ที่อัปเดตแล้วจากเซิร์ฟเวอร์มาเรนเดอร์
- มีระบบสลับมุมมอง 3D / AR / 2D ตามความพร้อมของอุปกรณ์
🔄
Event Flow
join ➔ quick_match ➔ match_found ➔ state_update ➔ move ➔ game_over
บทพูดหน้า 3: สถาปัตยกรรมของเกมเราใช้หลักการ Server-Authoritative ครับ โดยไคลเอนต์จะไม่มีสิทธิ์ตัดสินว่าตัวเองเดินถูกหรือชนะ แต่จะส่งเฉพาะพิกัด from/to มายังเซิร์ฟเวอร์ จากนั้นฟังก์ชัน rules.js จะตรวจสอบกฎ ถ้าถูกต้องจึงกระจาย state ใหม่กลับไปให้ผู้เล่นทั้งคู่ครับ
♟️ ตรรกะเกม & การทดสอบ

Thai Checkers Rules Engine

เขียนเป็น Pure Function พร้อม Unit Tests รับประกันความถูกต้อง 43 เคส

⚡
กฎกติกาหมากฮอสไทย
• กระดาน 8×8: ฝั่งละ 8 ตัว ขาวเริ่มก่อน
• บังคับกิน (Mandatory Capture): ถ้ามีตัวกินได้ ต้องกินเท่านั้น
• กินต่อเนื่อง: ค้นหาเส้นทางกินต่อเนื่องแบบ Recursive
• เลื่อนขั้นเป็นฮอส: เดินถึงแถวสุดท้ายคู่แข่ง
👑
พลังของฮอส
• Flying Move: เดินทแยงไกลกี่ช่องก็ได้หากไม่มีหมากขวาง
• Short Capture: กระโดดข้ามหมากคู่แข่งแล้วลงช่องถัดไปทันที (ทั้งหน้าและหลัง)

Flow การเล่นในห้องเรียน

ออกแบบให้เพื่อนทุกคนเข้าร่วมได้ง่ายภายใน 3 ขั้นตอน

1️⃣
สแกน QR Code หน้าห้อง
ฉายหน้า /qr.html ขึ้นจอโปรเจกเตอร์ เพื่อนในห้องเปิดกล้องมือถือสแกนเข้าเว็บได้พร้อมกัน
2️⃣
ตั้งชื่อ & จับคู่ด่วน
พิมพ์ชื่อ 2-12 ตัวอักษร -> กด "⚡ จับคู่ด่วน" เซิร์ฟเวอร์จะจับคู่แบบสุ่มสี (ขาว/ดำ) ให้อัตโนมัติ
3️⃣
เริ่มดวลบนโต๊ะเรียน
ผู้เล่นจะเห็นหมากของตัวเองอยู่ด้านล่างเสมอ แตะหมากเพื่อดูไฟเรืองแสงสีเขียวบอกตาเดิน แล้วแตะเพื่อเดิน
บทพูดหน้า 6: Flow การใช้งานออกแบบมาเพื่อห้องเรียนโดยเฉพาะครับ ผู้บรรยายเปิดหน้าจอ QR Code ขึ้นโปรเจกเตอร์ เพื่อนๆ สแกนแล้วกดจับคู่ด่วน ระบบจะจับคู่ให้อัตโนมัติและแสดงผลแบบเรียลไทม์ครับ
